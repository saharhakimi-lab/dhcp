01. מה זה DHCP?

פרוטוקול DHCP מקצה כתובות IP, מסיכת רשת, שער ברירת מחדל ושרתי DNS באופן אוטומטי לרכיבים ברשת דרך ארבעת שלבי תהליך DORA כולל Discover, Offer, Request ו-Acknowledge. במקרה של חוסר מענה, מופעל מנגנון החירום APIPA המקצה כתובת עצמית בטווח 169.254.0.0/16 המאפשרת תקשורת מקומית בלבד בתוך ה-LAN ללא יציאה לאינטרנט.

02. שאלות עומק והסברים מורחבים

למה שלב Request נשלח ב-Broadcast מוחלט גם ברמת ה-IP וגם ברמת ה-MAC? ▾

במידה וקיימים מספר שרתי DHCP ברשת, הלקוח עשוי לקבל מספר הצעות Offer. כאשר הלקוח שולח הודעת Request בשידור היקפי Broadcast לכל רכיבי המקטע (Dst MAC: FFFF.FFFF.FFFF), הוא מודיע לכל השרתים ברשת באיזו הצעה הוא בחר. בכך הוא מאפשר לשרתים שלא נבחרו לשחרר את הכתובת שהציעו בחזרה למאגר הכתובות (Address Pool).

מהם זמני חידוש החכירה (Lease Renewal T1 T2)? ▾

הלקוח אינו ממתין לתום זמן החכירה כדי לחדש כתובת: ב-50% מפרק הזמן (T1 Timer), הלקוח פונה ב-Unicast לשרת המקורי לבקשת חידוש. במידה והשרת לא משיב, ב-87.5% מפרק הזמן (T2 Timer), הלקוח יוצא ב-Broadcast לכל השרתים ברשת כדי למנוע נתוק תקשורת.

04. הגדרת שרת DHCP בנתב סיסקו (CLI)

משימת הגדרה:

יש להגדיר מאגר DHCP בשם LAN_POOL עבור הרשת 192.168.10.0/24 עם שער ברירת מחדל 192.168.10.1.

הזן פקודה ליצירת ה-Pool:
Router config
הנחיות לביצוע: הקלד את הפקודה ליצירת מאגר ה-DHCP לפי התבנית: ip dhcp pool LAN_POOL
Router enable Router configure terminal Router config Type the command to create DHCP pool and press Enter
Router(config)#

05. ניתוח תקלות מתקדם, מבדקי ידע ורפלקציה

🛑

שאלה קריטית בהנדסת רשתות: מי לא יקבל כתובת IP משרת ה-DHCP?

ניתוח עומק גבולות השידור (Broadcast Domains), חסימת L3 ופתרון DHCP Relay Agent.

כדי שמחשב יקבל כתובת IP אוטומטית משרת DHCP, עליו להשלים את שלב ה-DHCP DISCOVER. מכיוון שלמחשב הלקוח אין עדיין כתובת IP, הודעה זו נשלחת כ-Broadcast (שידור היקפי) לכתובת 255.255.255.255 ולכתובת MAC יעד FFFF.FFFF.FFFF.

❌ אלו המכשירים שלא יקבלו כתובת:

  • מחשבים ברשת פיזית / סאבנט אחרת: נתב (Router) חוסם הודעות Broadcast כברירת מחדל ולא מעביר אותן בין ממשקיו.
  • מחשבים ב-VLAN אחר: מתג (Switch) מבודד לחלוטין מתחמי שידור (Broadcast Domains) בין VLANs שונים גם אם הם על אותו מתג פיזי.
  • מחשבים שסובלים מנתק פיזי / הפסקת שירות: כבל מנותק, כרטיס רשת מנוטרל או שרת DHCP כבוי / מלא (Exhausted Pool).

💡 הפתרון: רכיב ראוטר משכבה 3 (Layer 3)

כדי לאפשר למחשבים ברשת / VLAN מרוחק לקבל כתובת משרת מרכזי, יש להגדיר ברכיב השכבה השלישית (Router או L3 Switch) מנגנון תיווך:

Router(config-if)# ip helper-address [DHCP_SERVER_IP]

פקודה זו מקבלת את ה-Broadcast Discover והופכת אותו ל-Unicast שנשלח ישירות אל שרת ה-DHCP המרכזי.
